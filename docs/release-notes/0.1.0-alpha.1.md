The first public alpha of **AlbumCraft**, a fast, simple photo organizer with a non-destructive editor, for Linux, Windows and macOS.

**Highlights**
- Library: folders scanned for JPEG, PNG, TIFF, WebP, GIF, BMP and camera raw files (shown through their embedded full-size preview); pick / reject flags, 1–5 stars, captions, tags, people, albums, search and filters; keyboard culling (`P`, `X`, `U`, `0`–`5`).
- Editor: one-click fixes (I'm feeling lucky, auto exposure, auto colour, auto contrast, auto straighten), Advanced sliders (white balance, exposure, highlights, shadows, blacks, contrast, saturation, vibrance, clarity, sharpening, noise reduction), 17 preset looks with intensity, effects (vignette, borders, instant-print frame, drop shadow, rounded corners, text), copy / paste edits. Originals are never modified.
- Sharing: export, collage, printing (Windows, or CUPS on Linux and macOS), slideshow with crossfades, pan and zoom and music, web gallery, slideshow movie (needs FFmpeg).
- Automation: `albumcraft --mcp`, an MCP server with 23 tools, working with or without the window open.

**Downloads**
- Linux x86_64: `albumcraft-…-linux-x86_64.tar.gz` (binary, icon, `.desktop` file).
- Windows x86_64: `albumcraft-…-windows-x86_64.zip`.
- macOS (Apple Silicon): `AlbumCraft-…-macos-arm64.zip` (an app bundle).

These builds are not signed. On macOS, right-click the app and choose *Open* the first time; on Windows, choose *More info* → *Run anyway* in the SmartScreen prompt.

**Known limitations**
- Printing assumes 5 mm margins on Linux and macOS; no duplex or quality options yet.
- Text overlays use one font and nine positions; no drag to place.
- Movie export needs FFmpeg on the `PATH`.
- Raw files are not developed from sensor data; edits work on the embedded preview.
