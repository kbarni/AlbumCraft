AlbumCraft 0.2.1 has the same features as 0.2, now in more package formats: an installer for Windows, and AppImage, Debian and Flatpak packages for Linux.

**New packages**
- **Windows installer** (`.msi`): installs AlbumCraft for all users in Program Files, adds a Start menu entry, and replaces an older version when you install a newer one. The portable `.zip` is still available.
- **Linux AppImage** (`.AppImage`): one file that runs on most distributions; make it executable and start it. It works with AppImageUpdate to download only the changes in later versions.
- **Debian and Ubuntu** (`.deb`): `sudo apt install ./albumcraft-0.2.1-linux-x86_64.deb` adds AlbumCraft to the applications menu.
- **Flatpak** (`.flatpak`): `flatpak install --user albumcraft-0.2.1-linux-x86_64.flatpak`. It can read pictures in your home folder and on external drives.
- `SHA256SUMS.txt` lists a checksum for every download.

**Small changes**
- The Windows program now carries the AlbumCraft icon, so it shows in Explorer and on taskbar pins.
- `albumcraft --version` prints the version.

**Downloads**
- Windows x86_64: `albumcraft-0.2.1-windows-x86_64.msi` (installer) or `.zip` (portable).
- Linux x86_64: `albumcraft-0.2.1-linux-x86_64.AppImage`, `.deb`, `.flatpak` or `.tar.gz`.
- macOS (Apple Silicon): `AlbumCraft-0.2.1-macos-arm64.zip` (an app bundle).

These builds are not signed. On macOS, right-click the app and choose *Open* the first time. On Windows, choose *More info* → *Run anyway* in the SmartScreen prompt.

**Known limitations**
- Printing doesn't work in the Flatpak yet. Use the `.deb` or the AppImage to print on Linux.
- The Flatpak keeps its own library, separate from other installs of AlbumCraft on the same computer.
- Raw files are not developed from sensor data; edits work on the embedded preview.
